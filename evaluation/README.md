# Evaluation protocol

Expand the included seed examples into at least 50–200 manually labeled role/profile pairs. Include exact keywords, synonyms, paraphrases, irrelevant profiles and ambiguous short profiles.

Labels can be 0–3 (irrelevant → highly relevant). Report Precision@5, Recall@10, MRR and nDCG@10. Split development and final evaluation sets. Record retrieval and reranking latency separately.
